## whoami

I'm a chef who cooks, but not in the kitchen. I solve problems for a living using 1s and 0s.

I write software for a living, for clients, and increasingly for myself. Mobile first, then web and backend because building a complete product requires more than one layer. I work remotely as a Software Engineer with a France-based company, freelance on the side, and build products of my own. Most are still works in progress. A few are out in the world. Shipping them is the part I enjoy most.

My GitHub bio says *"I dont know what i'm doing."* Still true, and I have made peace with it.
